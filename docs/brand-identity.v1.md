# 固定栏目头与组织落款 V1

依据用户在2026-11-23指定的已验证第001期深海蓝成图。本次将其作为品牌结构和视觉方向依据，不沿用先前橄榄色候选。栅格成图不能证明源字体或精确RGB；以下是依据视觉建立的**可复现工程标准与近似色号**，不是对原始设计文件的鉴定。SVG是依据参考形态建立的稳定实现，不声称取得官方源矢量。

## 生效与边界

- 新生产入口：`scripts/render-v04.mjs`。默认读取 `config/brand/identity.v1.json`，也可显式将该路径写入本期JSON的brand。
- 栏目、英文、组织文字必须逐字匹配，否则失败。期数须先由外部工作流将工作台整数格式化成 `NO.${String(n).padStart(3,'0')}`；渲染器仅接受`NO.`加至少三位数字。NO.000只用于工程样张，不代表真实一期。
- 本期design中的brandSignature以及colors.brandPink/brandSymbol不会改变固定品牌；加载器用固定规范替换品牌角色和色彩，报告记录最终实际计算样式。`textEmphasis.brandSignature`被拒绝，不能更换社区着色范围。
- brandGap与brandSymbolSize由固定规范接管；本期布局仍可调整brandAlign，背景的masthead/brand安全区控制组件整体位置。背景不同不意味着随意换品牌色；对比度不足时应调整背景或安全区。
- 规范JSON与两枚SVG登记在 `config/brand/identity.v1.lock.json`；摘要不符或锁登记缺项直接失败。旧候选路径、临时Logo配置直接失败。品牌变更须新增版本并明确迁移入口，不覆盖V1、不删除锁来绕过保护。
- `config/versions.lock.json`及第002期v2归档完全不变。旧入口仅用于历史回归，不作为新一期生产入口。此升级仍在V0.4开发分支/PR中，未合并前不得声称main已启用。

## ICON四色圆环背景

`assets/brand/ring-reference.v1.svg`是依据用户图二建立的**视觉重建参考，不是原始官方矢量**，未作为精确官方Logo锁定；以后取得原始可用文件时应新增资产版本替换参考。黄#ffbf0b、绿#009578、蓝#0077b5、紫#7d4497为近似示意颜色。不得将棋盘格透明预览底画入背景。

制作背景时保留四色曲线环带与中空的识别关系，整体放大、向画幅边缘偏移，裁出轻柔的半圆环/局部环带。不做整颗高饱和Logo，不随意生成随机圆弧。可从整体不透明度4%—10%起试；7%仅是工程示意，不是每期硬阈值。位置、尺度和轻微旋转可随构图变化，避免主体文字和落款周围出现明显色块/边缘冲突。仍须人工在手机阅读尺度核验“可辨识但不抢阅读”。

建议先完成无字场景，再以稳定矢量参考合成环带；**含圆环的最终无字背景必须整体交给用户确认**，确认后再计算PNG/安全区摘要并正式排版。不得在用户确认后追加圆环而沿用旧摘要。本次仅补充参考资产、规则和工程示意，不向每张背景运行时自动叠加圆环，不强制复制旧成图的静物或构图。
