# Pink Bloom 内容生产工作流

## 各部分是什么

| 部分 | 职责 | 当前状态 |
| --- | --- | --- |
| 生产说明 / Prompt | 说明栏目目标、来源、禁止事项、审核要求、使用哪个已确认布局 | 可在项目说明或聊天中使用；不必另建项目，也不会因写了 prompt 自动接通工具 |
| Notion | 保存每期原文、来源、审核结论、背景选择与最终图片 | 工程尚未接入，未自动读取或回传；以后可在连接获授权、指定页面可访问时由助手读取 |
| Codex / 聊天助手 | 理解任务、读可访问资料、组织内容和配置、运行工程、解释报错、展示结果 | 当前可操作云端工程；未建立无人值守流水线 |
| GitHub 仓库 | 保存排版程序、设计规范、配置、素材与变更历史 | 已建立；不是在线图片生成服务 |
| Codex Cloud | 运行 Node.js 与 Playwright，实际计算并输出 PNG | 已验证；新任务可重新检出仓库、安装、运行，不要求个人电脑开机 |
| 图像制作工具 | 制作/编辑无字背景，人工确认可用性 | 不在现有工程中自动调用，也没有接 AI 图片 API |
| 聊天窗口 | 触发任务、看预览、给反馈、接收生成文件 | 已可交付当前云任务中的 PNG；不等于自动写回 Notion 或自动发微信群 |

## 现在能实际运行的流程

1. 提供每期已经确认的文案和可使用的无字背景；目前可以直接在聊天中提供，不要求先建立 Notion 数据库。
2. 助手将内容保存成 `content/*.json`，并选择 `config/issues/*.json`。背景档案提供安全区和视觉重心，设计规范提供字体、颜色和层级。
3. 在 Codex Cloud 中运行仓库程序，先生成预览和检查报告。
4. 人工检查文字与背景的位置关系、字形、行间留白；需要时调整配置。新增视觉结构才改 HTML/CSS。
5. 检查通过后输出 2160×2700 PNG，助手可在聊天中展示和提供文件链接。
6. 工程与配置通过 Git 提交保留版本。大量每期输出默认不进 GitHub；最终归档和发布当前仍是人工流程。

示例命令：

```bash
npm run preview -- --input content/issue-demo.json --output output/issue-demo.html
npm run render -- --input content/issue-demo.json --output output/issue-demo.png
```

当前真实能力已经覆盖本地 JSON → 配置排版 → 预览/检查 → PNG。第001期参考图的新视觉结构仍待实现，并不因为已有配置系统就自动具备该样式。

## 以后接入 Notion 后的目标流程

1. **任务触发**：用户指定某一期 Notion 页面和要求。生产说明可长期保存，但每期仍需有明确输入与触发。
2. **读取资料**：在 Notion 连接已获授权、页面可访问的前提下，助手读取原文、来源和审核状态；工程本身目前还没有这一步。
3. **文案整理与人工专业审核**：AI 可提出整理草稿，医护确认医学内容。未经审核可做标明状态的排版测试，不应作为正式发布内容；正式发布使用已审定稿。审定后不在排版时擅自改字，若改动医学表达需重新审核。
4. **选择背景**：优先复用已筛选背景库；只有需要新画面时再制作无字背景，不必每一期重新生成。人工确认素材、留白和构图，建立对应背景档案。
5. **选择与调整布局**：结合内容长度和背景构图，从已实现布局中选择配置。助手可以建议参数，但当前没有程序自动构图功能。需要新结构时才扩展版式能力。
6. **云端预览与检查**：运行 GitHub 保存的工程，在 Cloud 中生成预览，检查溢出、遮挡、裁切、内容完整性，再由用户看视觉效果。
7. **定稿与交付**：输出高清 PNG，在聊天中展示并提供文件。以后可增加回传 Notion，记录用稿、版本和图片；回传功能当前未实现。微信群发布不在本阶段范围内。

这是一条未来的协作链，不是已经安装完成的自动化。当前由聊天任务驱动，没有定时调度、24小时常驻工作进程或后台自动监听 Notion。

## 是否需要另建项目和 Prompt

不强制需要。可以继续在当前项目/聊天推进，工程规则已经在仓库的 `AGENTS.md`，设计与布局规则在版本化配置中。另建一个专门的内容生产项目有助于整理素材和日常操作说明，但它不会自动继承本聊天的工具授权、仓库运行环境或所有上下文，需要明确关联仓库、页面与布局版本。

建议把生产说明写成短而明确的操作约定，避免复制整个工程实现。例如未来可以说：

> 请制作「康复小纸条」第XXX期。资料位于指定 Notion 页面，使用页面记录的人工审核稿和已确认布局版本，优先复用背景库。先生成预览和检查报告，保持医学原文和知识点顺序；有修改建议请单独列出，不直接替换审核稿。确认视觉后再交付高清 PNG。

上面只是未来任务示例，不代表已发起 Notion 调用或自动获得访问权限。本次没有创建自动化 Skill、Token 或新服务。
