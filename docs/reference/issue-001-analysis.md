# 第001期参考图：工程参数提取稿

状态：draft。此稿记录用户所给合成参考图的视觉方向，不表示已经完成母版复刻或医学审核。未改动现有运行模板。机器可读提取稿见 `issue-001-extraction.v0.1.json`，它不是运行时 `--config`。

## 提取依据与可信度

本次直接观察聊天中的图片，没有取得可读取的本地原文件，未验证原图像素尺寸，也没有执行像素取色或字体识别。下面的坐标、色值、字号是按 1080×1350 目标画幅归一化的目测建议值，不是从原图读出的精确参数。视觉结构判断较可靠，数字需要下一轮真实 HTML 预览校准。

## 视觉识别

- 暖白、米色纸感背景，柔和自然光影。树叶集中在右上，杯子/书位于右下，织物/花瓣集中在底部；中央留出大面积浅色空间供文字使用。
- 正文直接排在背景留白上，没有当前占位版式那样覆盖正文的大白面板。
- 深棕文字承担阅读，橄榄绿用于重点标题，陶土粉用于期号/编号/品牌点缀，浅橄榄与浅粉承担柔和提示底纹。
- 主标题、知识点标题与正文均偏中文衬线风格。柔和感来自背景光影、暖色、行间留白、字体形态及层级共同作用，不建议通过整体降低文字透明度实现。
- 四行知识点以统一网格组织：圆形底色图标 → 细竖线 → 斜体编号 → 绿小标题与深色说明。细横线分隔行，内容保持顺序。

字体候选以 Noto Serif SC 为起点，不断言与参考图字体一致。当前工程只加载 Noto Serif SC 600 标题字体，正文是 Noto Sans SC；参考图正文风格需要增加 Noto Serif SC 400 的加载与验收。字形匹配和柔和程度需看预览后由用户确认。

## 文字与背景的空间关系

参考图不是一个均匀内边距的大卡片，而是分区组合：

1. 顶部栏目与期号，约 x=72、y=32，横向组织。
2. 主体标题/引导语/知识点，约 x=68、y=126、宽934、高822，内容流向下展开。
3. 提醒条，约 x=60、y=966、宽850、高118，右侧给杯子留空间。
4. 底部落款，约 x=616、y=1244、宽410、高66，与织物/花瓣错开。

右上叶片、右下杯书及底部织物需要分别标记避让区。这些数值是拟议区域边界，不要求把每一行文字固定在这些坐标。正文内部应使用自然内容流；容量不足则报告，不改写医疗文案。

原合成图适合作为视觉参照，不能直接作为生产背景，因为原有文字、图标和标识已经烘焙进像素。后续应取得原始无字背景，或另行制作/编辑出无字背景并人工检查；未经处理不能声称背景和文字已分离。原图没有在本次被上传 GitHub。
